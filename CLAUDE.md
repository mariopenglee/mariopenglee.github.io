# CLAUDE.md

Personal website for Mario Peng Lee. React + TypeScript + Vite, terminal/TUI
aesthetic (monochrome, IBM Plex Mono, boxed panels). Builds to `/docs` for
GitHub Pages (mariopenglee.com). Blog posts are markdown files in `src/posts/`
with `title` / `date` / `summary` frontmatter; the filename is the URL slug.

## Writing voice

Any prose ghost-written for Mario (blog posts, bios, copy) must match his
voice. Derived from his own writing samples:

**Hard rules**
- NO em dashes, ever. Use commas, colons, parentheses, or split the sentence.
- No "AI-sounding" prose: no mic-drop one-liners, no "Here's the thing",
  no triadic flourishes ("fast, parallel, and terrible"), no staccato
  fragments for drama, no theatrical section headers.
- Headers are lowercase, plain, and descriptive ("the setup", "what broke"),
  not clever.

**Voice markers (use naturally, not all at once)**
- First person, thinking out loud: "to be honest", "seems to me",
  "my intuition is", "my guess is", "my view is", "I'd expect", "honestly".
- Opinionated but hedged: state the take first, qualify it second
  ("probably", "likely", "for sure", "unclear so far", "in principle").
- Parenthetical asides for nuance or wry comments (like this).
- Casual modifiers: "pretty", "basically", "much", "for sure".
- Contractions always. Connectors like "and", "so", "as", "since" over
  formal ones like "moreover", "thus", "furthermore".
- Define an acronym once inline, then use it freely: "internal
  representation (IR)".
- Practical structure when discussing research: name the risk, then the
  mitigation; propose the smallest clean experiment first; control one
  variable at a time.
- Endings look forward with curiosity ("would love to look into it",
  "probably interesting to explore whether X") rather than punchlines.
- No emojis.
